# 취미 · 냉장고

취미 > 냉장고(`/hobby/fridge`)는 냉장고에 무엇이 있는지 한 화면에 보는 페이지다. 아이패드를 냉장고 옆에 세워 두고 쓰는 것을 기준으로 만들었다. 넣고 빼는 수고를 줄이는 게 목표라 **냉장·냉동 두 칸, 이름, 넣은 날**만 기록한다. 개수·양·유통기한·세부 칸은 적지 않는다. 2026-11-08 코드 기준.

## 화면

- 세 칸: 냉장실 · 냉동실 · 이걸로 해먹기. 아이패드 가로(사이드바 포함 1180px)에서 페이지 스크롤 없이 한 화면에 들어가고, 800px 이하에서는 위아래로 쌓는다.
- 재료 타일: 아이콘·이름·넣은 날(오늘, 어제, 그 밖은 M/D). 칸마다 **오래 둔 것부터** 보여준다. 아이콘은 입력받지 않고 이름에 든 낱말로 고른다(`lib/fridge.ts`의 `fridgeIcon`).
- 빼기: 타일을 **꾹(0.38초) 누른 채로 끌어서** 아래에 올라오는 "다 먹었어요"나 "버렸어요"에 놓는다. 반대 칸에 놓으면 그 칸으로 옮긴다(넣은 날은 그대로). 탭만 하면 아무것도 바뀌지 않고 방법을 알려준다. 끄는 동안에는 화면 스크롤과 하단 알림을 막는다.
- 넣기: 머리의 "넣기"나 칸의 ＋. 시트에서 냉장/냉동을 고르고, 쉼표로 이름을 적거나 칩을 누른다. 칩은 "최근에 다 먹은 것"(90일 안, 지금 냉장고에 없는 것, 최근 순 12개)과 "집밥에 나오는 재료"(냉장고에 없고 늘 있는 재료도 아닌 것)다. 넣은 날은 서버가 서울 날짜 오늘로 정한다.
- 되돌리기: 넣기·빼기·옮기기 직후 알림의 "되돌리기". 넣기는 지우고(`fridge_delete`), 빼기는 되살리고(`fridge_restore`), 옮기기는 원래 칸으로 옮긴다. 확인 창은 없다.
- 이번 달 버린 수를 머리에 보여준다.
- 다른 기기(폰)에서 바꾼 것도 보이도록 화면으로 돌아올 때와 2분마다 다시 읽는다. 끄는 중에는 다시 읽지 않는다.
- 코드: `src/components/fridge-board.tsx`, `src/app/fridge.css`, 진입 카드는 `menu-hub.tsx`의 `hobbyMenus`, 데모 데이터 `src/lib/demo-fridge.ts`. 데모(`/demo?view=/hobby/fridge`)는 화면에서만 바뀌고 저장하지 않는다.

## 이걸로 해먹기

[집밥](../meals/README.md) 요리의 **메인 재료**를 냉장고 재료와 맞춘다(`lib/fridge.ts`의 `matchMeals`).

- 재료 다 있음은 "지금 바로", 하나만 없으면 "하나만 있으면". 냉장고 재료를 하나도 쓰지 않는 요리는 빼고, 오래 둔 재료를 쓰는 요리가 앞에 온다.
- 이름 맞추기: 같은 이름(띄어쓰기 무시)이 먼저다. 아니면 냉장고 이름이 재료 이름을 품을 때 맞춘다("다진 돼지고기" ↔ 돼지고기, "냉동밥" ↔ 밥). 한 글자 재료("무")는 "단무지"에 걸리지 않도록 같은 이름만 맞춘다.
- 냉동실 재료는 ❄︎로 표시한다(해동 필요). 없는 재료는 점선으로 "없음".
- **늘 있는 재료**(김치·된장·고추장·간장·고춧가루·마늘·참기름·굴소스·두반장·참치)는 냉장고에 적지 않아도 있다고 본다. 화면 설정은 없고 `fridgeStaples` 상수를 고친다.
- 요리를 누르면 그 요리에 쓰는 냉장고 재료를 테두리로 짚고 나머지는 흐리게 한다.

## 저장·권한

- 표: `db/migrations/021_fridge_items.sql`의 `fridge_items`(name 40자, place `cold`/`frozen`, added_on, removed `eaten`/`wasted`, removed_at, version). 뺀 재료는 지우지 않고 removed를 남겨 "최근에 다 먹은 것"과 버린 수에 쓴다. 넣기 취소만 행을 지운다.
- 조회 `GET /api/fridge`(`{ items, recent, wasted_this_month }`), 쓰기는 공통 `POST /api/commands`의 `fridge_add`(한 번에 20개, 공백·중복 정리)·`fridge_remove`·`fridge_restore`·`fridge_move`·`fridge_delete`(서버 `src/server/fridge.ts`).
- 냉장고는 함께 쓰므로 넣은 사람과 관계없이 공간 안의 누구나 빼고 옮긴다. 같은 재료를 동시에 바꾸면 version 검사(`VERSION_CONFLICT`)로 막고 화면은 서버 목록으로 다시 맞춘다.
- scope: 집밥과 같은 부엌 영역이라 `meal:read`·`meal:write`를 같이 쓴다. 새 scope를 만들면 기존 AI 연결을 다시 승인해야 해서 나누지 않았다.
- MCP: 모든 `fridge_*` 명령이 `webOnlyCommands`라 도구로 나가지 않고 MCP 채널에서 거부한다. 영수증 사진으로 한꺼번에 넣기 같은 MCP 도구는 필요해지면 그때 연다.
