## 자산현황 페이지

### 목적
- 민섭, 장미 2명의 자산의 현황을 그룹핑하여 시계열로 증감현황과 종합현황을 본다.
- MCP 를 통해 자산을 쉽게 등록한다.

### 화면 구성
- 사용자별로 자산 그룹별 금액, 비율 을 볼수 있다.
- 등록일 기준으로 자산 그룹별 데이터를 DB에 저장하고 시계열로 증감을 비교한다.
- 그룹의 통화종류, 자산종류 등으로 여러 그룹핑 단위로 볼수 있다.
- 사용자별, 종합 등으로 합쳐서 볼수있다.
- 시간 증가에 따라 그래프로 증감을 잘 볼수있고 표, 그래프 등 여러 적합한 표시장법으로 자산을 표시한다.

### MCP
- 사용자별로 자산 그룹별 데이터를 전달받아 받은날 기준으로 DB에 저장한다.
- ai agent에게 자산의 raw 데이터를 그룹화 시킬수 있는 룰을 조회한다.
 + 자산 그룹 메타 데이터 * 자산 그룹 매치 패턴
 + (지금 내가 적어놓은것을 좀 더 다음어서 ai agent가 보고 사용할 수 있게 최적화 필요)
- 사용자, 전체 기준으로 그룹별 데이터를 조회 할 수 있다.
