# MONO 가계부

## 최종 설계 결정

2026-09-09. 사용자 요청에 따라 두 독립 설계 [A](proposal-a.md), [B](proposal-b.md)를 비교했다. B의 **요약 / 분류 분석 / 거래 내역 / 파일 관리** 4탭과 A의 기간별 평균·금액 검증 기준을 조합했다. PC는 비교 피벗과 넓은 요약, 모바일은 2×2 지표·분류 순위·소분류 펼치기·거래 목록으로 제공한다. 원본 [HTML](cash-money.html)과 [DESIGN](DESIGN.md)은 참고이며 현재 동작은 이 문서와 코드가 기준이다.

## 저장과 갱신

- Neon `cash_files` 한 행에 `.xlsx` 원본 전체(bytea), 정규화 파일명, SHA-256, 메타데이터를 저장한다. 거래별 DB 행과 파일 버전 이력은 없다.
- 키는 `(household_id, filename_key)`. 한글 NFC·앞뒤 공백·대소문자를 정규화하며 경로/제어문자/Excel 임시파일은 거부한다. 표시 이름은 확장자를 뺀 파일명이며 로그인 계정과 자동 매칭하지 않는다.
- 같은 이름은 최신 원본으로 교체한다. `version`은 동시 수정 충돌 검사에만 사용하며 이전 파일을 복원하는 버전이 아니다. 이름이 다르면 새 자료다.
- 파일 선택 → 서버 검증 미리보기 → 확인한 파일 적용. 감소한 기간/건수도 표시하지만 과거 삭제·수정을 반영할 수 있도록 적용은 허용한다. 잘못된 파일은 기존 내용을 변경하지 않는다.
- 파일별 적용이며 다중 선택 전체가 하나의 트랜잭션은 아니다. 각 파일 성공·실패를 표시한다. 같은 해시 재시도는 변경 없음. 오래된 미리보기의 다른 내용은 409 충돌.
- 파일당 3,000,000바이트, 50,000행, 101열, 압축 해제 선언 크기 40MB. 한 번에 10개, 공간당 20개. XLSX 첫 번째 시트만 분석하며 원본 전체는 보존한다. 암호화와 필수 업무 필드 수식은 지원하지 않는다.
- 서버리스 디스크/공개 URL에 원본을 쓰지 않는다. 원본 다운로드도 웹 세션과 공간 권한을 검사한다. 가계부 데이터는 공개 데모와 기존 공통 snapshot에 포함하지 않는다.

## 분석 규칙

- `KRW`를 우선하고, 비어 있을 때 원본 통화가 KRW인 `금액`만 대체한다. 원화는 행별 원 단위 반올림 후 합산한다. 원본 통화·금액은 상세에 함께 보여준다. 임의 환율을 적용하지 않는다.
- 음수/0원을 보존하며 중복으로 보이는 거래도 제거하지 않는다. 음수는 동일 유형 합계를 차감한다.
- 날짜를 Excel serial/문자열에서 달력 날짜로 파싱한다. 서버 시간대에 따라 날짜가 움직이지 않는다.
- 수입·지출만 기본 분석. 이체·차액 및 `선물 / 계좌이체` 지출은 제외한다. 원본에는 그대로 남아 있고 파일 관리의 유형별 건수와 다운로드에서 확인할 수 있다.
- 기본 시작은 2021-01, 종료는 최신 기록 월이다. 자료가 모두 2021년 이전이면 실제 시작 월을 사용한다. 전체 기간 버튼으로 2021년 이전도 조회할 수 있다.
- 마지막 거래일을 월 입력 완료일이라고 추정하지 않는다. 파일별 마지막 날짜와 서로 다른 자료 범위를 표시한다. 월평균 분모는 선택한 달력월 수로 고정한다. 기간 내 무거래 월은 0원이다.
- 수입−지출은 계좌 잔액이나 자산이 아니다. 저축률은 수입이 양수일 때만 `(수입−지출)/수입`이다. 제외 필터가 적용되면 해당 분석 범위의 비율이다.
- 지출 피벗 증감은 직전 열 대비이며 양수 기준만 비율을 계산한다. 현재 0은 -100% 표시. 길이가 다른 연도 비교는 생략한다.
- 원본의 기타 펼치기, 수입 포함/지출 제외, 큰 지출 제외, 대분류/소분류, 월/연 피벗, 추이, 상세 드릴다운과 Markdown 요약을 이식했다. 로그 축은 음수·0을 보존하는 대칭 로그 확대와 정확한 값 표로 제공한다.
- 검색·결제수단별 지출·50건 페이지 조회·CSV 내보내기를 추가했다. CSV 문자열은 수식 실행을 막는 텍스트로 내보낸다. MD는 상세 거래 없이 현재 기간/필터/집계 규칙과 월·연·분류 집계를 포함한다.

## 분석 화면과 상세 조회

2026-09-09 재대조: [원본 기능 대조표](feature-audit.md). 요약 / 분류 분석 / 거래 내역 / 파일 관리와 별도 `/cash/old`를 제공한다.

- 첫 화면은 연도 비교 표, 연·월별 흐름, 선택 기간 항목 비중이다. 전체 기간 합계 KPI와 결제수단별 지출 카드는 제거했다. 기간·분석 조건은 접어두고 현재 범위를 요약한다.
- 연도별 월평균은 **항목별 월 평균 지출** 패널을 연다. 분류·소분류 평균, 비중, 막대를 제공한다. 평균 금액에서 거래를 열고 닫으면 원래 평균 패널로 돌아간다.
- 분류별 기간 셀은 거래 상세, 기간 합계 셀은 분류·소분류 비중, 분류/소분류 평균은 해당 항목 추이, 전체 항목 비교는 여러 항목의 추이다. 연별 평균은 표시 연도 수, 월별 평균은 표시 달력월 수로 나눈다. 연도 요약의 월평균은 해당 연도 선택 달력월 수로 나눈다.
- 연도별 흐름에서 연간 합계/월평균 비교를 전환해 부분 연도의 개월 수 차이를 확인할 수 있다.
- Chart.js 4.4.6으로 반응형 차트·툴팁·범례 토글·금액/비중 전환을 제공한다. 작은값 확대는 환불/0을 유지하는 대칭 로그다. 비중 분모는 해당 기간의 전체 수입 또는 지출이며 0 이하이면 표시하지 않는다.
- PC는 비교 표, 모바일은 4열 연도 표와 기간 선택형 항목·비중·작은 추이·소분류 목록이다. 모바일에서 부가 연도 열은 생략한다. 그래프는 컨테이너 크기로 다시 그리며 PC SVG를 축소하지 않는다.
- 상세 패널 정렬·50건 페이지·CSV는 패널 범위에만 적용한다. 그래프는 페이지에 보이는 50건이 아닌 전체 매칭 거래에서 집계한다. URL·원래 필터·위치를 보존한다.
- `가계부(old)`는 원본 HTML을 앱 안에서 실행하고 엑셀 API만 연결한다. 원본의 금액·완료월 규칙을 보존하므로 새 분석과 차이가 있을 수 있다. [단일 HTML 페이지 가이드](../single-html-pages.md)를 따른다.

공유 공간 구성원은 조회 가능하다. 교체는 원래 등록자 또는 관리자만 가능하다. 사용자 이름/파일명을 접근 권한으로 사용하지 않는다. MCP 노출은 이번 범위에 없으며 기존 coffee/wine 토큰은 사용할 수 없다. 별도 캐시는 프로세스 메모리의 파싱 결과이며 DB 거래 저장을 대신하는 영속 데이터가 아니다. 재시작/캐시 만료 시 원본에서 다시 계산한다.


## 운영

웹 `/cash` → 파일 관리에서 업로드한다. 최초 등록이나 운영자 CLI 작업은 `scripts/cash-upload.ts <xlsx 경로...>`를 사용한다. `.env.local` 개발 DB가 기본이며 운영은 Node의 `--env-file=.env.vercel.local`로 명시한다. CLI도 동일 검증·권한·교체 서비스를 거치고 저장된 원본 해시를 대조한다. 개발/운영 적용 전에 `db:migrate`를 수행한다.

원본 XLSX는 Git에서 제외한다. 실제 거래나 파일을 테스트 fixture·공개 데모에 복사하지 않는다. 원본 보관·외부 백업은 사용자가 관리하며 앱의 파일 교체는 되돌릴 수 없다. 일반 `db:export` 지원 범위는 운영 문서를 확인하고, 전체 복구에는 PostgreSQL 백업을 사용한다.

검증: `tests/cash.test.ts`, `tests/integration/domain.test.ts`의 cash 블록, `tests/e2e/app.spec.ts`의 cash 흐름. 로컬 `_test` DB의 합성 파일만 사용한다.
