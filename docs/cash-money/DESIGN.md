# 가족 가계부 설계 (single-file HTML)

## 1. 개요

- 같은 폴더의 `{구성원 이름}.xlsx` 파일을 브라우저에서 직접 읽어 시각화하는 단일 HTML 가계부.
- 서버/빌드 없음. 사용자가 `index.html`을 열어 바로 사용.
- 라이브러리는 CDN으로 불러옴 (SheetJS, Chart.js).
- **데이터는 살아있음**: xlsx 원본은 가계부 앱에서 export하여 계속 새로운 행이 추가됨. 새 구성원이 추가될 수도 있음. → HTML은 데이터 스냅샷이 아니라 현재 폴더의 xlsx를 매번 새로 읽어 집계한다.

### 데이터 소스 (참고용 현재 상태)

> 아래 표는 설계 시점의 스냅샷이지 고정값이 아님. 실제 동작은 로드 시 xlsx에서 동적으로 계산.

| 파일 | 행 수 | 기간 | 비고 |
|---|---|---|---|
| `민섭.xlsx` | 14,700 | 2011-12 ~ 2026-05 | 대출이자 100건, 기타 868건 |
| `장미.xlsx` |  4,041 | 2000-01 ~ 2025-12 | 대출이자 0건, 기타 73건 |

공통 컬럼: `기간`, `자산`, `분류`, `소분류`, `내용`, `KRW`, `수입/지출`, `추가입력`, `금액`, `화폐`, `자산.1`

`수입/지출` 값: `수입`, `지출`, `이체입금`, `이체출금`, `차액수입`, `차액지출`

### 파일 로드 방식 (단일 HTML 유지의 핵심)

`index.html`을 `file://`로 열면 브라우저 보안 정책상 같은 폴더의 xlsx를 `fetch()` 할 수 없음. **File System Access API의 폴더 선택을 메인 방식으로 채택.**

- 최초 진입 시 "폴더 선택" 버튼 노출 → 사용자가 `cashmoney` 폴더 권한 부여.
- 폴더 안의 모든 `.xlsx` 파일을 자동 스캔해 구성원으로 인식.
- 권한 핸들을 `IndexedDB`에 저장해 다음 진입 시 다시 묻지 않음 (브라우저가 권한 유지 허용 시).
- "새로고침" 버튼으로 폴더 내용을 즉시 재읽기.
- 대상 브라우저: Chrome 또는 Edge.

## 2. 데이터 처리 규칙

1. **수입/지출 필터링**: `수입/지출` 컬럼이 정확히 `"수입"` 또는 `"지출"` 인 행만 사용. (`이체*`, `차액*` 전부 제외)
2. **선물 > 계좌이체 제외**: `분류 == "선물" && 소분류 == "계좌이체"` 인 지출은 집계에서 제외.
3. **1000만원 이상 지출 제외 토글**: 체크 시 `수입/지출 == "지출" && 금액 >= 10,000,000원` 인 행은 모든 집계/표시에서 제외. 자동차 구매·전세금 같은 일회성 큰 지출을 빼고 통상 패턴을 보기 위함. 기본 OFF.
4. **수입항목 선택 (포함 필터)**: 전체 수입 분류(대분류) pill 목록에서 선택된 분류만 집계·표시(다중 선택, 파란색 활성화). 아무것도 선택하지 않은 경우 전체 수입 포함. "전체 보기" 버튼으로 초기화. (기존 부모님 수입 필터도 여기서 부모님 제외/포함으로 자유롭게 조절)
4-1. **지출항목 제외 (제외 필터)**: 전체 지출 분류(대분류) pill 목록에서 선택된 분류를 집계·표시에서 제외(취소선/붉은색 활성화). 대출이자 등 특정 분류 제외도 여기서 처리.
5. **구성원 이름**: 파일명에서 확장자를 제거한 값 (`민섭.xlsx` → `민섭`). 폴더 안 모든 `.xlsx`를 구성원으로 인식 (개수/이름 하드코딩 없음).
6. **금액 단위**: 내부 계산은 원 단위로 하고, 표시할 때만 만원으로 변환.
   - 1억 이상: `1억 2,345만원`
   - 1000만 이상 1억 미만: `#,###만원`
   - 1만 이상 1000만 미만: 소수점 1자리 `523.4만원`
   - 1만 미만: `3,200원`
7. **날짜**: `기간` 컬럼에서 `YYYY-MM-DD` 만 추출해 사용.

### 분석 기간 (동적 계산)

데이터가 계속 추가되므로 표시·집계 기간을 다음 규칙으로 매 로드 시 결정한다.

- **시작**: `2021-01-01` 고정. (그 이전 행은 집계/표시에서 제외)
- **종료 (마지막 완료 월)**: **폴더 안 전체 구성원**의 데이터가 해당 월 마지막 날까지 채워진 가장 최근 월. UI 상태 표시는 월말 기준만 노출하며 구성원별 개별 범위는 표시하지 않음.
  - 구체적 알고리즘:
    1. 각 구성원 파일에서 `2021-01-01` 이후의 데이터만 본다.
    2. 각 구성원별로 "마지막으로 데이터가 존재하는 날짜" `lastDate[i]` 를 구한다.
    3. 각 구성원별로 `lastDate[i]` 가 그 달의 말일이면 그 달까지 "완료", 아니면 직전 달까지 "완료" (`completeUpto[i]`).
    4. **전체 구성원**의 `completeUpto[i]` 중 **최댓값(가장 최근 완료 월)**이 분석 종료 월. (어느 한 구성원의 데이터가 짧아도 다른 구성원의 최신 데이터 기준으로 표시)
  - 부분 입력된 진행 중인 달은 UI 안내 띠에 "현재 진행 중: 2026-05 (아직 미반영)" 표시.
- **사용자 오버라이드**: 상단 컨트롤에서 시작/종료 연도를 임의로 변경 가능. 단 시작은 2021 이상으로 클램프.

### "기타" 분류 처리 제안

`기타` 분류가 민섭 868건/장미 73건으로 비중이 크고, 실제로는 `내용`에 의미 있는 텍스트가 들어있음 (예: "ps5 게임", "현관문", "안경", "자동차 구매"). 다음 두 가지로 처리:

- **(A) 그대로 표시**: 다른 분류와 동등하게 `기타`로 묶어 보여줌. (기본)
- **(B) 기타 펼치기 모드**: 상단 토글. 켜면 `기타` 분류를 한 단계 더 들어가 `내용` 텍스트로 그룹핑해 보여줌. 빈 `내용`은 "기타-미기입"으로 묶음. 동일 텍스트가 많은 항목(예: "기타", "관세") 위주로 노출되어 어디에 돈을 썼는지 더 잘 보임.

## 3. 화면 구성

### 3.1 최상단 컨트롤 바

- **데이터 소스**: "폴더 선택" 버튼. 권한 부여 후엔 폴더 경로와 각 구성원 파일의 `최종 데이터 일자`를 작은 글씨로 표시.
- **새로고침** 버튼: 디스크에서 다시 읽어 최신 행 반영.
- **Export Summary** 버튼: 현재 필터가 적용된 요약 데이터를 마크다운 파일로 다운로드. 다른 AI 세션에 가족 소비/수입 패턴을 전달하기 위한 용도. 상세 거래까지는 포함하지 않고 연도·월·분류 단위 집계만 포함.
- **구성원 선택 (라디오)**: 단일 선택. 옵션은 `[전체]` + 폴더 안 각 xlsx 파일에서 자동 생성된 구성원 (예: `[전체] [민섭] [장미]`). 기본값 `전체`.
- **연도 범위**: from-to 선택. 시작 기본=2021, 종료 기본=전체 구성원 기준 동적 계산된 마지막 완료 월의 연도. 시작 최솟값 2021 클램프.
- **옵션 체크박스**:
  - "기타" 분류 펼치기 (기본 OFF) - 켜면 `기타` 분류를 `기타·{내용}` 으로 세분화
  - **1000만원 이상 지출 제외** (기본 OFF)
- **수입항목 선택**: 전체 데이터에 존재하는 수입 분류(대분류) 목록을 알약(pill) 형태로 나열. 클릭 시 해당 분류만 집계·표시(포함 필터, 다중 선택 가능). 선택된 분류는 파란색 활성화 스타일로 표시. 아무것도 선택하지 않으면 전체 수입 포함. "전체 보기" 버튼으로 한 번에 초기화.
- **지출항목 제외**: 전체 데이터에 존재하는 지출 분류(대분류) 목록을 알약(pill) 형태로 나열. 클릭 시 해당 분류를 모든 집계·표시에서 완전히 제외(제외 필터, 다중 선택 가능). 선택된 분류는 취소선/붉은색 스타일로 표시. "전체 해제" 버튼으로 한 번에 초기화. 기본값: 제외 없음.
- **현황 안내 띠**: 예) `분석 범위: 2021-01 ~ 2026-04 (월말 완료 기준). 진행 중인 달: 2026-05.`

### 3.1.1 섹션 내부 컨트롤 (수입/지출 분류 섹션 전용)

- **시간 단위 토글**: `[연도별] / [월별]` 라디오 형태.
- **연도 선택 (월별 모드에서만 표시)**: 셀렉트박스. 옵션은 `yearFrom ~ yearTo` 범위 안 연도. 기본=종료 연도.

### 3.2 핵심 3개 섹션

#### 1. 연도 요약 (Year Overview)

| 연도 | 수입 | 지출 | 월 평균 지출 | 모은돈 | 저축률 |
|---|---|---|---|---|---|
| 2025 | 8,500만원 | 5,200만원 | 433만원 | 3,300만원 | 38.8% |

- **월 평균 지출** = 해당 연도 지출 합계 / 그 해의 분석 대상 월 수.
  - 일반 연도: 12개월 기준.
  - 마지막(진행) 연도: `computedEnd.month` 개월 기준 (예: 2026년 4월까지 완료면 4개월).
- 클릭 (셀 별 분리):
  - **연도 셀** (또는 행의 빈 영역) → 해당 연도 전체 거래 (수입+지출 혼합).
  - **수입 셀** → 해당 연도 **수입만** 거래 상세.
  - **지출 셀** → 해당 연도 **지출만** 거래 상세.
  - **월 평균 지출 셀** → 해당 연도의 항목별 월 평균 지출 상세 (분류별로 "월 평균 / 연 합계 / 비중" 표). 목적: 매달 어느 분류에 평균적으로 얼마가 나가는지 한눈에 보기.
    - 분류 행 클릭 → 소분류가 있으면 소분류 목록 표시 → 소분류 클릭 → 그 분류·소분류·그 연도의 거래 목록으로 드릴다운. 소분류가 없으면 바로 그 분류·그 연도의 거래 목록.

#### 2. 수입 분류 (Income by Category)

- **표 (세로 형태)**: 행=분류 (합계 내림차순), 열=기간, 값=합계 금액. 마지막 열은 `합계` 및 `평균`. 마지막 행은 `합계` 및 `평균`.
  - **평균 컬럼**: 실제 입력 데이터가 존재하는 기간 개수로 나눈 평균값 (월별: 해당 연도에 입력된 최대 월 수 기준 예: 6월까지 있으면 `/ 6`, 연도별: 표시된 연도 수 기준).
- **섹션 컨트롤**: `[연도별] / [월별]` 토글 + (월별 시) 연도 셀렉트.
  - 연도별: 열 = `yearFrom ~ yearTo` 안의 각 연도.
  - 월별: 열 = `1월, 2월, ..., 12월` (선택된 연도 1년치, 항상 12개 컬럼).
- **클릭 인터랙션**:
  - **기간 셀 / 합계 셀**: 클릭 시 우측 슬라이드 패널로 거래 상세 내역 표시.
  - **분류/소분류 행의 "평균" 셀**: 클릭 시 화면 중앙 큰 모달로 해당 분류의 시계열 **Line Chart** 표시 (각 포인트에 금액 라벨 표기).
  - **맨 아래 "합계" 행의 각 년도/월 셀**: 클릭 시 화면 중앙 큰 모달로 해당 시점의 **분류별 Bar Chart** 표시 (막대 옆/위에 금액 라벨 표기).
  - **맨 아래 "합계" 행의 "평균" 셀**: 클릭 시 화면 중앙 큰 모달로 **모든 분류가 표시되는 다중 시계열 Line Chart** 표시.
  - **맨 아래 "합계" 행의 "합계" 셀**: 클릭 시 화면 중앙 큰 모달로 **전체 총합계 추이 Line Chart** 표시.

#### 3. 지출 분류 (Expense by Category)

- 2번과 동일 구조 (type만 `지출`).
- "1000만원 이상 지출 제외" 옵션이 켜져있으면 단일 지출 ≥1000만원 행은 빠져있는 상태로 표시.
- **변동 강조 표시**: 가계부의 핵심이 지출 관리이므로 각 셀에 전기 대비 변화율을 표시.
  - 비교 기준: 같은 행(분류)의 직전 열 값. 연도별 모드면 직전 연도, 월별 모드면 직전 월.
  - 기본 색상: 검정/회색 (지출이라고 다 빨강으로 칠하지 않음).
  - **변화율 ≥ +20%**: 빨강 톤 배경 + 글자, 작은 `+xx.x%` 표시.
  - **변화율 ≤ -20%**: 파랑 톤 배경 + 글자, 작은 `-xx.x%` 표시.
  - 그 외 (절대값 < 20%): 기본 색상 + 작은 `±xx.x%` 회색 표시.
  - 전기 값이 0이거나 없을 때: 기본 색상, 변화율 표시 없음.

### 3.2.1 섹션 접기

- 섹션 1, 2, 3 모두 헤더의 제목(▼/▶) 클릭으로 본문 접고 펼치기.
- 접혔을 때 섹션 컨트롤(연도/월별 토글 등)은 보임. 표만 숨김.
- 기본값: 모두 펼침.

### 3.2.2 Export Summary (MD)

다른 AI 세션에서 가족 소비·수입 패턴을 빠르게 파악하도록 요약 마크다운을 다운로드한다. 현재 적용된 모든 필터(구성원/기간/기타/1000만원/수입항목선택/지출항목제외)가 그대로 반영된 상태로 export.

파일명: `cashmoney-summary-YYYY-MM-DD.md`

포함 섹션:

1. **메타데이터**: 생성일, 분석 범위, 구성원 목록 + 각 최종 일자, 적용 필터 요약
2. **연도별 요약 표**: 연도/수입/지출/모은돈/저축률/월평균지출
3. **월별 요약 표** (전체 기간)
4. **수입 분류 × 연도** 피벗 (분류별 합계 내림차순)
5. **지출 분류 × 연도** 피벗 (분류별 합계 내림차순)
6. **최근 완료 연도 항목별 월 평균 지출** (최근 1년 패턴 강조용)
7. **최근 완료 월 핵심 지표** (수입/지출/모은돈/전년 동월·전년 동기 누적 비교)

거래 단위 상세는 의도적으로 제외. AI가 패턴을 분석할 때 필요한 집계만 압축적으로 제공.

### 3.3 상세 패널 & 차트 모달

#### (A) 우측 상세 패널 (Detail Panel)
- 우측 슬라이드 인.
- **그래프 보기 버튼**: 헤더의 닫기 버튼 옆. 기본 OFF.
- 컬럼: `날짜 / 구성원 / 분류·소분류 / 메모 / 금액`.
- 상단 요약: 수입/지출/차액 합계.
- **기본 정렬**: 날짜 내림차순. 금액 정렬 지원 (3-state).
- ESC 키로 닫기.

#### (B) 중앙 대형 차트 모달 (Central Chart Modal)
- 화면 중앙에 팝업 형태로 크게 렌더링.
- **금액 라벨 직접 표시**: Bar 차트의 막대 옆/위 및 단일 Line 차트의 각 포인트 위에 금액(`fmt`)을 직접 표시.
- **작은 데이터 가시성 확보**:
  - Bar 차트: 최소 막대 길이(`minBarLength: 8`) 확보로 작은 항목도 바 형태와 색상이 식별됨.
  - Line 차트: 포인트 크기 확대(`pointRadius: 5`) 및 라벨 표기로 작은 값도 시각적으로 명확히 인지.
  - **로그 스케일 토글 버튼**: 큰 값과 작은 값의 차이가 매우 클 때 상단의 `📈 작은값 확대 (로그)` 버튼으로 모든 항목의 상대적 추이를 확인 가능.
- **축 라벨 명시**: X축과 Y축에 `분류`, `기간`, `금액` 등의 명확한 타이틀 및 포맷 라벨 표기.
- 닫기: 우측 상단 ✕ 버튼, 바깥 딤 영역 클릭, ESC 키 지원.

## 4. 표시 규칙

### 금액 포맷

- 기본: `#,###만원` (만원 단위 반올림 정수). 예: `1,235만원`.
- 1,000만원 미만: 소수점 1자리. 예: `523.4만원`.
- 100만원 미만: `12.3만원`.
- 1만원 미만: `3,200원`.
- 음수: 빨강 + 마이너스 부호. 예: `-120만원`.

### 그래프 규칙

- **모든 뷰에 라인 차트 1개 기본 포함** (연도 추이 또는 월별 추이).
- 막대/도넛은 데이터 형태에 따라 적절한 것을 추가.
- 분류별 색상은 전역에서 일관성 유지 (분류명 → 색상 매핑 고정).

### 인터랙션

- 그리드/차트 셀/항목 클릭 → 우측 사이드 패널(데스크탑) 또는 하단 모달(모바일)로 상세 내역.
- 상세 내역 컬럼: `날짜 / 구성원 / 내용(메모) / 분류·소분류 / 금액`.
- 상세 내역에서 정렬 (날짜, 금액) 가능.
- 상세 내역 CSV 내보내기 버튼.

## 5. 추가 제안 기능 (일반 가계부 서비스 분석)

> 시중 가계부(뱅크샐러드, 가계부, Money Lover, Toshl, YNAB) 공통 기능 중 이 데이터로 의미 있게 만들 수 있는 것 위주.

### 5.1 추천 (구현 우선)

1. **TOP N 인사이트 카드**
   - 이번 달 가장 많이 쓴 분류 3개
   - 이번 달 단일 지출 TOP 5 (날짜·내용·금액)
   - 전년 동월 대비 증감 (수입/지출/모은돈)

2. **분류 비중 도넛 차트** (선택한 기간의 지출/수입 비중)

3. **연 단위 비교**
   - 올해 vs 작년 누적(YTD 기준 동일 월까지) 막대 차트
   - "5월까지 누적 지출이 작년 동기간보다 12% 적음" 같은 카피.

4. **검색**
   - 내용/분류/소분류 키워드로 항목 검색 (상단 검색바, 즉시 필터링).

5. **자산(결제수단)별 통계**
   - `자산` 컬럼을 활용해 카드/계좌별 사용 금액 랭킹. 어떤 카드를 가장 많이 쓰는지.

6. **고정지출 추정**
   - 매월 반복되는 `통신비`, `구독`, `주거비`, `보험금` 같은 분류의 월평균을 카드로 노출.

### 5.2 여유 있으면 (구현 후순위)

7. **예산 모드**
   - 분류별 월 예산을 LocalStorage에 저장. 진행률 막대로 시각화 (`이번 달 식비 65% 소진`).

8. **이상치 감지**
   - 단일 트랜잭션이 해당 분류 중앙값의 3배 이상이면 표 행을 하이라이트.

9. **사용자별 비교**
   - 민섭 vs 장미 같은 기간 지출 비교 (분류별 stacked bar).
   - 한 명만 단독 부담하는 항목 식별.

10. **세션 상태 저장**
    - 마지막에 본 필터/탭 상태를 LocalStorage에 저장.

11. **다크 모드** 토글.

### 5.3 의도적으로 안 넣는 것

- 자산(은행 잔액) 추적: 거래 데이터만으로는 잔액을 정확히 추정하기 어려움 (초기 잔액 미지정). 별도 입력 UI 만들 만큼 가치가 큰지 의문.
- 자동 카테고라이저: 이미 가계부 앱에서 분류해 둔 데이터이므로 불필요.
- 클라우드 동기화: 단일 HTML 파일 목표와 어긋남.

## 6. 기술 스택 / 파일 구조

```
cashmoney/
├── index.html      # 모든 코드 포함 (HTML + CSS + JS)
├── 민섭.xlsx
├── 장미.xlsx
└── DESIGN.md       # 이 문서
```

- **XLSX 파싱**: [SheetJS](https://cdn.sheetjs.com/) (CDN, `xlsx.full.min.js`).
- **차트**: [Chart.js](https://cdn.jsdelivr.net/npm/chart.js) (CDN).
- **로드 방식**:
  - `fetch('민섭.xlsx')`로 직접 로드 시도.
  - 브라우저 CORS로 `file://`에서 막히는 경우, 상단에 "xlsx 파일을 드래그&드롭 하거나 선택하세요" 인풋 폴백 제공.
  - 파일 목록은 하드코딩 대신 사용자가 추가/제거할 수 있게 multi-file input 지원.

### 성능

- 민섭 14,700행 + 장미 4,041행 = 약 1.9만 행. SheetJS로 파싱 후 한 번 인덱싱하면 모든 집계가 즉시 가능.
- 그룹핑은 단순 JS reduce로 처리. 별도 워커 불필요.

### 호환성

- **메인 타깃: Chrome 또는 Edge** (File System Access API 필요).
- 미지원 브라우저는 진입 시 안내 후 동작 보장 안 함.
- 데스크탑 우선.

### 데이터 갱신 흐름

1. 가계부 앱에서 `민섭.xlsx`, `장미.xlsx` 등을 폴더에 덮어쓰기.
2. 브라우저에서 `index.html` 페이지의 "새로고침" 버튼 클릭 (또는 폴더 권한이 있으면 F5).
3. 시작 2021, 종료(전원 월말 완료) 자동 재계산 후 화면 갱신.
- 모든 상태는 LocalStorage에 저장하지 않는 한 페이지 새로고침 시 기본값으로 돌아감.
