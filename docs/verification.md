# MONO 검증 기록

2026-09-08. 실행 결과와 미검증 범위를 구분한다. 수치/배포 ID는 영구 보장이나 현재 운영 재고가 아니라 해당 확인 시점의 기록이다.

## 2026-09-09 가계부 통합

- 두 독립 화면 설계를 비교해 4탭 및 PC 피벗/모바일 순위·카드를 선택했다. 원본 XLSX 두 개는 거래 행으로 변환 저장하지 않고 파일명별 최신 bytea로 저장한다.
- Node 22 lint/typecheck/build 통과. Vitest 36개, Playwright 16개(PC 8 + 모바일 8) 통과. 파일 관리 조회 분리 후 가계부 PC/모바일 2개를 재검증했다.
- 파일명 Unicode 정규화, 원자적 교체·동일 파일 재시도·409 충돌, 파일 손상, 다른 공간 다운로드 차단, 작성자/관리자 교체 권한, MCP 채널 거부, 외화 KRW 우선·음수·0·평균 분모·중복 거래 보존을 확인했다.
- 원본 XLSX XML을 별도 Python 표준 라이브러리로 읽어 날짜 범위·건수·전체 수입/지출·2021년 이후 분석 제외 적용 합계를 대조했다. 두 파일 모두 새 파서/집계와 일치.
- 개발/운영 Neon에 005 적용 및 최초 등록 완료. 민섭.xlsx 15,026행, 699,343바이트(2011-12-31~2026-08-02); 장미.xlsx 4,538행, 172,003바이트(2000-01-01~2026-06-30). 저장된 원본 SHA-256과 로컬 파일 일치. 이 수치는 최초 등록 시점의 메타데이터다.
- 원본은 .gitignore로 제외하며 합성 테스트 파일만 사용했다. 운영 전 기존 컬렉션 JSON 백업을 로컬 backups에 저장했다.

## 2026-09-09 커피 목록 개선

- 이미지 없는 PC 열 목록/모바일 두 줄 배치, 브랜드 원두 바로가기, 탭·상세 왕복 필터 보존, 가격 정렬·검색 확장·초기화를 구현했다.
- Node 22에서 lint, typecheck, Vitest 28개, Playwright 14개(PC 7 + 모바일 7), 프로덕션 빌드 통과.
- 추가 브라우저 회귀: 중량 없는 48,000원, 0원, 가격 미입력, 판매 가격 양방향/환산 가격 정렬, 브랜드별 개수·목록·상세 왕복·새로고침·초기화. PC/모바일 캡처로 목록 배치 확인.
- 테스트용 데이터는 로컬 `_test` DB에만 생성. 운영 페이지 접근 및 기존 표시 문제도 로그인된 Chrome에서 확인했다.

## MONO 이름·홈·문서 정리

- 앱 표시 이름 MONO, 개인 워크스페이스 소개, 모듈 진입 중심 홈으로 변경.
- 인증·공간 ID·재고·MCP 식별자·운영 URL은 유지. DB migration 추가 없음.
- Node 22에서 TypeScript·프로덕션 빌드 통과.
- Vitest 28개(도메인/인증/사진 15, 입력/이관 9, 와인 가격/필터 4) 통과.
- Playwright 12개(PC 6 + 모바일 6) 통과. 브랜드 변경에 맞게 접근성 텍스트 기대값을 갱신하고 등록·입고·소비·취소·사진·OAuth 동작 검사를 유지.
- 문서 상대 링크 검사: 누락 없음. 초기 설계와 실제 구현 불일치 정리, 과거 Airtable 지침을 archive로 분리.

## 검증의 한계

- 모바일은 iPhone 크기의 Chromium 자동 테스트이며 실제 iOS Safari 기기 검증이 아니다.
- ChatGPT/Codex 실제 계정 연결, 모든 AI 클라이언트의 사진 첨부 파일 전달 능력은 별도 확인이 필요하다.
- 앞선 배포 뒤 이 컴퓨터에서 운영 도메인 연결 거부가 발생해 일부 운영 UI 재확인이 제한됐다. Vercel Ready, DB 대조, 로컬 테스트와 운영 UI 확인을 같은 의미로 쓰지 않는다.
- 최신 보안 취약점 여부, 클라우드 플랜/복구 보존 기간은 이 기록으로 보장하지 않는다. 배포 시 현재 상태를 확인한다.

재실행 명령과 위험별 검사 선택은 [개발 가이드](development.md)에 있다. 실제 비공개 데이터/스크린샷/백업은 Git에 넣지 않는다.
