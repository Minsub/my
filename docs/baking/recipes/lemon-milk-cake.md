# 레몬우유케이크

- 출처: Merrybonbon Baking Class 수업 자료 (손글씨 메모 포함)
- 틀: 1호 원형틀
- 구성: 반죽(시트) + 레몬커드 + 우유크림
- 굽기: 160℃ 25분 (인쇄본 24분 → 메모로 25분)

손글씨 메모는 ✍️로 표시했다. 사진으로 읽기 어려운 글자는 `(?)`를 붙였다.

## 1. 반죽 (1호 원형틀)

| 재료 | 양 | 메모 |
| --- | ---: | --- |
| 전란 | 120g | |
| 설탕 | 66g | ✍️ 따로 계량 |
| 꿀 | 18g | |
| 박력분 | 63g | |
| 버터 | 12g | ✍️ 우유와 같이 계량 |
| 우유 | 22g | ✍️ 버터와 같이 계량 |
| 레몬제스트 | 1g | ✍️ 추가 |

1. 전란에 설탕, 꿀을 넣어 공기포집한다.
   - ✍️ 믹서 5단으로 걸쭉하게 휘핑 → 이후 1단으로 1분 휘핑(기포 정리)
2. 충분히 공기포집되면 가루를 넣고 섞는다.
3. 데운 버터·우유를 넣고 잘 섞는다.
   - ✍️ 버터·우유는 40℃ 정도
   - ✍️ 반죽을 조금 덜어 버터·우유에 먼저 섞은 뒤, 본 반죽에 넣고 퍼올리듯이 섞기
4. 틀에 팬닝해 오븐에 굽는다: 160℃ ~~24분~~ ✍️ **25분**
   - ✍️ 예열 160℃

## 2. 레몬커드

| 재료 | 양 | 메모 |
| --- | ---: | --- |
| 전란 | 64g | |
| 설탕 | 61g | |
| 레몬즙 | 50g | ✍️ 생레몬 2개(?), 제스트 2g 추가 |
| 버터 | 20g | |
| 젤라틴 | 1 → ✍️ ½ | 생략 가능. 인쇄본에 단위 없음(판젤라틴 장 수로 보임). ✍️ 찬물에 불려 키친타월로 물기 짜기 |

1. 전란에 설탕, 레몬즙을 넣고 가볍게 섞는다.
2. 중불에서 알맞은 농도가 될 때까지 끓인다. ✍️ **80℃**
3. 농도가 되면 버터, 젤라틴을 넣고 섞어 마무리한다.
4. 체에 내려 차갑게 식혀 쓴다.
