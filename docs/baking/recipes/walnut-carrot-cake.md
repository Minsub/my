# 호두당근케이크

- 출처: Merrybonbon Baking Class 수업 자료 (손글씨 메모 포함)
- 구성: 당근시트 + 크림치즈크림 + 크럼블
- 굽기: 시트 170℃ 40분/50분, 크럼블 170℃ 20분, 호두 170℃ 7~8분
- 보관: 시트는 냉동 1달, 실온 2일

손글씨 메모는 ✍️로 표시했다. 사진으로 읽기 어려운 글자는 `(?)`를 붙였다. 단위는 g.

## 1. 당근시트

| 재료 | 양 | 메모 |
| --- | ---: | --- |
| 계란 | 3개 | ✍️ 특란, 개당 60g~ |
| 흑설탕 | 210g | ✍️ 180g까지 줄여도 됨 |
| 카놀라유 | 220g | ✍️ 포도씨유 가능 / 올리브유 ✕ |
| 중력분 | 255g | 체 침 |
| 베이킹파우더 | 3g | ✍️ ↑ 위로 부풂 |
| 베이킹소다 | 3g | ✍️ ← → 옆으로 퍼짐 |
| 시나몬파우더 | 4g | ✍️ 기호에 따라 넣거나 빼도 됨(?) |
| 채썬 당근 | 180g | ✍️ 채칼 |
| 구운 호두 | 40g | ✍️ 아래 전처리 |

**호두 전처리 ✍️**

1. 끓는 물에 1분 데쳐 불순물(떫은 맛) 제거
2. 오븐 170℃ 7~8분 굽기

**만드는 법**

1. 계란, 흑설탕을 넣고 풀어준다.
2. 카놀라유를 넣고 섞는다.
3. 체 친 중력분, 베이킹파우더, 베이킹소다, 시나몬파우더(가루류 모두)를 넣고 섞는다.
4. 토핑(당근·호두)을 넣고 날가루가 없어질 때까지만 섞는다.
5. 유산지를 깐 원형팬에 반죽을 1/3, 2/3씩 나눠 담는다.
6. 170℃로 예열한 오븐에서 굽는다.
   - ✍️ 1/3 반죽 팬 → **40분**, 2/3 반죽 팬 → **50분**
   - ✍️ 오븐에서 바로 꺼내기
- ✍️ 시트는 냉동 1달 / 실온 2일 보관 가능

## 2. 크림치즈크림

| 재료 | 양 | 메모 |
| --- | ---: | --- |
| 크림치즈 | 200g | ✍️ 필라델피아, 차갑게 |
| 슈가파우더 | 80g | |
| 생크림 | 170g | ✍️ 동물성, 차갑게 |

1. 크림치즈와 슈가파우더를 먼저 부드럽게 휘핑한다. ✍️ 고속
2. 생크림을 여러 번에 나누어 넣으며 휘핑한다.

- ✍️ 깍지: 804
- ✍️ 냉동 가능. 해동은 실온에서 키친타월 위에 올려두기
