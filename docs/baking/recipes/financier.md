# 휘낭시에

- 출처: YouTube 영상 설명란 (캡처)
- 분량: 오발틀 12개
- 굽기: 190℃ 12분 (예열, 우녹스 컨벡션 오븐)
- 보관: 서늘한 실온 5일, 오래 두려면 포장해서 냉동

## 만드는 법

1. **헤이즐넛 버터** — 냄비에 실온 버터를 넣고 가열해 갈색 버터를 만든다. 쓰기 전까지 잠시 둔다.
2. **흰자 섞기** — 볼에 흰자, 설탕, 꿀, 소금을 넣고 잔거품이 일 때까지 거품기로 가볍게 섞는다.
3. **가루 넣기** — 아몬드가루, 강력분, 박력분을 체 쳐 넣고 가루가 안 보일 때까지 섞는다.
4. **버터 넣기** — 60℃ 전후로 맞춘 헤이즐넛 버터를 넣고 겉돌지 않게 완전히 섞는다.
5. **굽기** — 틀에 80~90% 채우고 예열한 오븐에서 190℃ 12분.

## 식감과 보관

- 당일: 겉이 바삭하다.
- 완전히 식혀 비닐·밀폐용기에 두면 바삭함이 사라지고 수분이 돌아 겉과 속이 모두 촉촉해진다.
- 서늘한 실온 5일. 오래 두려면 잘 포장해 냉동.
